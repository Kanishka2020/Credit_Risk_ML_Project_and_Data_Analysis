# Credit_Risk_ML_Project_and_Data_Analysis

In this project, we build an end-to-end credit risk machine learning pipeline using BigQuery and TensorFlow. Starting from data modeling and ingestion, we design a scalable data warehouse, perform feature engineering, and develop a classification model to predict loan default risk.

The model generates risk scores to support automated and consistent lending decisions, reducing reliance on manual underwriting.

Finally, we leverage advanced SQL in BigQuery to analyze credit behavior and extract actionable insights for business stakeholders.
